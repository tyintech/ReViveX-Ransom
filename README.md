# ReViveX Ransom

[English](README.en.md) · [下载](https://github.com/tyintech/ReViveX-Ransom/releases) · [恢复原理](docs/原理说明.md) · [技术说明](docs/技术说明.md) · [作者网站](https://www.xtyue.com/)

**被勒索病毒加密的 Hyper-V 虚拟机磁盘（VHDX）数据找回工具。**

虚拟机的 `.vhdx` 文件被勒索病毒加密后打不开、挂载不了时，ReViveX Ransom 可以从中按**原来的文件名和目录**找回文件。已在 **.6zdxfy 变种**加密的实际案例中验证有效。

作者：**陈涛 alan chen** · 联系：**1315333@qq.com** · 开源协议：AGPL-3.0-or-later

## 主要功能

- **一键自动恢复**：选好被加密的文件和保存位置，点“开始自动恢复”即可，程序自动判断该用哪种方式。
- **按原名、原目录找回**：恢复出的文件保持原来的文件夹结构和文件名，而不是一堆编号文件。
- **找回已删除的文件**：虚拟磁盘里曾被删除、但数据还没被覆盖的文件，也会单独找回。
- **自动分类**：结果分为“可用 / 待确认 / 疑似损坏 / 缩略图缓存 / 已删除文件”，先看“可用”即可。
- **支持超大磁盘**：十几 TB 的虚拟磁盘也能处理；进度、速度实时显示。
- **随时暂停、继续**：可以随时安全取消，之后点“继续上次任务”从中断处接着做，不用从头再来。
- **可用快速临时盘**：可以指定一块 SSD 存放中间数据，加快速度；恢复出的文件仍写到你选的保存位置。
- **绝不改动原文件**：只读取源文件，不修改、不覆盖；整理结果只移动不删除，可以撤回。
- **浏览和导出**：在“结果与验证”里按目录、类型浏览，搜索、勾选后只导出需要的文件。
- 中文 / English 界面，浅色 / 深色外观。

也可以用于：普通磁盘镜像（`.img`、`.dd` 等）、损坏的 ZIP 压缩包、PNG / SQLite 文件抢救等，见[技术说明](docs/技术说明.md)。

## 使用方法

1. **准备**：立即停止使用被加密的磁盘；最好先把被加密的 `.vhdx` 复制一份，对副本操作。准备一块空间足够的**另一块**硬盘保存结果。
2. **选择文件**：打开软件，在“恢复文件”中选择被加密的 VHDX 文件（扩展名可能被改成 `.vhdx.6zdxfy` 之类，直接选它）。
3. **选择保存位置**：选择另一块硬盘上的文件夹。可选：再选一个快速临时目录（如 C 盘 SSD）。
4. **开始**：恢复方式保持“自动恢复（推荐）”，点“开始自动恢复”。界面会显示当前阶段和进度，大磁盘需要较长时间，请保持电脑开机。
5. **查看结果**：完成后自动跳到“结果与验证”，可浏览、搜索并导出文件；也可以直接打开保存位置里的 `最终结果` 文件夹。

中途需要停止，点“安全取消”；之后在“结果与验证”里点“打开已有任务”选中该任务，再点“继续上次任务”。

## 恢复结果在哪里

保存位置里会新建一个任务文件夹，其中：

| 文件夹 / 文件 | 内容 |
| --- | --- |
| `最终结果\可用` | 检查通过、可以直接使用的文件（按原目录存放） |
| `最终结果\待确认` | 无法自动检查的文件，请打开确认 |
| `最终结果\疑似损坏` | 检查发现问题的文件，可能部分内容有误 |
| `最终结果\缩略图缓存` | Windows 自动生成的 Thumbs.db 缩略图缓存 |
| `最终结果\已删除文件` | 曾被删除后找回的文件，同样分为以上几类 |
| `清单.jsonl` | 每个找回文件的原路径、保存位置、大小和校验值 |
| `未恢复清单.jsonl` | 没能找回的文件及原因 |

上级目录名无法确认的文件会放在 `_上级目录名丢失_编号` 文件夹里。

## 注意事项

- 本软件**不是解密工具**：被病毒加密覆盖的那部分数据无法找回，不能保证 100% 恢复。
- 恢复结果请保存到**另一块健康的硬盘**，不要写回被加密的磁盘，并预留足够空间。
- 恢复出来的程序、脚本、宏文件请先隔离检查，**不要直接运行**。
- 恢复不确定时，先看 `可用` 文件夹；`疑似损坏` 中的文件内容可能不完整。
